One of my biggest gripes with using Claude in the CLI is you never fully know what tools are at your disposal. For a large org it can quickly get out of hand with all of the skills, plugins, and MCPs.

That's why I created claude-catalog.

It's a Claude Code plugin that opens a local web UI showing every skill, MCP tool, plugin, and slash command installed in your environment — with automatic usage tracking, search, sparklines, and a stale filter so you can see what to delete.

Two commands to install inside Claude Code:

/plugin marketplace add tysondoberneck/claude-catalog
/plugin install catalog@claude-catalog

https://github.com/tysondoberneck/claude-catalog
